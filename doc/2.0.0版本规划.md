# 2.0.0 范围与交付状态

更新日期：2026-11-13。当前源码版本为 `2.0.1`。

2.0.0发布后的用户实测发现设置页分组导航点击异常，2.0.1对此修复，并补充真实点击和Computer Use回归；验证范围见 [2.0.1修复验收](2.0.1修复验收.md)。其余2.0范围保持不变。

## 当前决定

2.0范围内的功能开发、已发现缺陷修复及自动化验收已经完成。项目负责人于2026-11-13在源码提交后追加授权发布2.0.0，并计划从上一版1.4.1实测公网应用内更新。其余真实24小时长测、真机专项和多人内测未执行，不计为测试通过。

正式版使用v2.0.0标签和Latest Release，重新构建Windows_v2.0.0_Setup.exe；发布前校验版本、资产名、大小和SHA-256，发布后检查旧版更新器能否识别。完整结果与范围见 [验收记录](2.0.0验收记录.md)。

| 数据与性能 | v5紧凑存储、重建式迁移、备份恢复、分钟汇总、全系统快照及性能预算 |
| 采集与自动化 | 单进程/进程树/同名组、等待与启动目标、方案模板、定时/日志打点、停止与导出、pmctl与无窗口模式 |
| 长时间监控能力 | 退出取证、重启续接、工具恢复、存储空间守卫、数据库健康与数据质量统计 |

| 界面与配置 | 卡片/列表、响应式布局、快捷键、统一通知、窗口状态、备份管理、延迟渲染 |

“具备长时间监控和恢复能力”不等于已经完成真实24小时实测；两者在验收记录中分开记录。

## 验证与提交状态

- 2.0.0正式版以通过验收的源码快照 `1fd5279` 为基础，2.0.1增加设置页分组导航修复；已完成的CI、测试和安装记录见对应验收文档。

- 当前补丁版本与数据库结构为 `2.0.1` / schema v5。
- 未执行项目和发布动作不写成“通过”或“已发布”。
