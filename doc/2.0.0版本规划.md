## 当前决定

2.0范围内的功能开发、已发现缺陷修复及本次自动化验收已经完成，按项目负责人决定提交并推送源码。其余真实24小时长测、真机专项、多人内测和正式公网更新检查本次不执行，不再阻塞源码提交，也不计为测试通过。
