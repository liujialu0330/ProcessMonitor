# 2.0.0 开发与验收记录

更新日期：2026-11-13。发布版本：`2.0.0`；下列前期验收快照版本为 `2.0.0-beta.1`。

2.0 范围内的功能开发和已发现缺陷修复已完成。源码提交后，项目负责人追加授权发布正式版2.0.0，并从上一版1.4.1实测应用内更新。正式安装包重新构建，不将beta安装包改名后发布；前期验收结果与正式包的版本、摘要分别记录。

## 本次提交范围的决定

项目负责人于 2026-11-13 决定继续提交、推送，以下未执行项目不再作为本次源码提交的前置条件：

- 安装版真实连续24小时浸泡。
- 系统休眠/唤醒、注销/关机、热键冲突、多屏/DPI、权限和外部图片粘贴等剩余真机专项。
- 至少3人、5个工作日的多人内测及真实用户旧库验证。
- 从已安装的1.4.1经公网下载、退出、覆盖安装到2.0.0的完整用户操作链，由项目负责人发布后实测。

这些项目未执行，不记为测试通过。本次在原仓库发布v2.0.0，不创建第二仓库；发布前运行构建自检与安装冒烟，发布后核对公网latest、安装包摘要及1.4.1更新器解析结果。测试工具和操作手册保留。

## 更新与回退的覆盖范围

模拟更新包含正常下载、同版本不更新、坏摘要、坏大小、非法初始域名及非法重定向拒绝。使用源码生产更新器和冻结旧版更新器，传输连接本机模拟服务，负载保持真实CI安装包的原名和原字节；没有模拟成已发布的正式版本。1.4.1更新器自身不校验SHA-256，演练在下载后另行核对文件摘要。

- 首次升级：旧版3400条原始指标记录按既定合并规则转为2200条，逐行符合期望；新增任务5个周期、两指标共10条，备注与打点保存正常。
- 回退A：保留v5库覆盖安装1.4.1，原2210条样本不变；通过旧版界面新增19条。再升级2.0后，原数据和这19条的时间、指标、数值均逐行一致，合计2229条，备注与打点保留。
- 回退B：另存当前v5库，恢复迁移备份并启动1.4.1；3400条原始记录与升级前一致，升级后的新任务不在旧备份中，符合备份时点语义。

A/B使用 [15fa596构建](https://github.com/liujialu0330/ProcessMonitor/actions/runs/43347793677)。它与最终验收快照仅差一个工作流触发契约测试，程序与打包输入源码相同。最终快照的安装包随后也已完成本机安装、自检、卸载与体积复验。所有操作使用隔离数据目录，日常数据文件内容和修改时间均未改变。
