# 分析交互与导出一致性阶段验收

记录日期为 2026-11-18，本阶段归档主分支源码。新增功能列在更新日志的“未发布”段。已发布的 2.0.3 安装包及其验证另行记录。[更新日志](../CHANGELOG.md) · [2.0.3 发布说明](2.0.3发布说明.md) · [指标采集与权限优化阶段验收](2026-11-15_指标采集与权限优化_阶段验收.md)

## 本阶段实现

- 分析页“打点区间”支持通过按钮或 F2 重命名基线及普通打点。同一区间有两个真实端点时可选起点或终点。编辑按数据库 ID 定位，覆盖同名、同时刻和名称恰为“开始”或“结束”的打点。相邻区间、图表和下一份报告采用更新后的名称。
- 悬停读数过长时在图卡内显示省略号，鼠标停留可查看完整信息。跨图时同步当前可见曲线的十字线，图卡宽度与选区保持稳定。概览拖动中断时恢复上次确认的范围。摘要表、重命名按钮与区间表支持 Tab 导航。
- 监控和分析页共用内存单位选择，支持自动、KB、MB、GB。切换后以现有样本换算容量读数，差值按自身量级选单位。容量纵轴可在深度放大时使用更细的精度。
- 命令行组合导出与阶段快照固定采样截止时间及打点。基线和轮次参考值取同一次启动内截至锚点的样本。空分析快照保留 CSV 元数据和表头，同一时刻的打点在摘要 CSV 各自保留区间。
- 分析页导出和复制结论等待当前时间范围、打点名称、成员和分段判定就绪。成员或分段读取失败时，页面标注上一次的缓存结果。刷新成功后可继续导出和复制。

## 审查与验证

阶段审查覆盖打点编辑、图表交互、单位换算、采样边界和导出一致性。提交前另外复现了选区更新时旧数据被用于导出，以及分段查询失败时旧判定混入当前结果这两种情况。修复后验证了预设范围切换到自定义、两组自定义起止切换、保存对话框期间换范围，以及分段查询失败后的恢复。

| 项目 | 结果 |
| --- | --- |
| 完整功能回归 | 5,225 项通过、44 项跳过、14 项未选中，0 失败 |
| 导出与分析专项 | 226 项通过 |
| 视觉回归 | 43 项通过 |
| 源码入口自检 | 11 步通过，含 v1 至 v5 迁移、采集、打点、报告、命令行应答及正常退出 |
| Windows 真实窗口 | 双主题下验证窄窗布局、细刻度及键盘导航。另用隔离数据验证 800×700 窗口中的分段失败提示、导出拦截及刷新后恢复 |
| 代表样本 | 2 GiB 私有字节每轮增长 32 KB。历史采样用 KB 显示至 2,097,216 KB，较上次 +32 KB，较基线 +64 KB |

功能回归使用离屏 Qt，包含慢速用例，选择范围为 `not perf and not soak and not gui_real`。真实窗口及源码入口自检使用独立临时数据目录。
