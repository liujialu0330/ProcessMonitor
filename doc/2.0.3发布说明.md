# 进程监控助手 v2.0.3

发布日期为 2026-11-16。

## 主要更新

- 新任务的 CPU 使用率按整机逻辑处理器时间容量归一为 0～100%，覆盖单进程、进程树和同名进程组。
- 指标实际返回权限不足时，可保存任务并以管理员身份重启，也可继续采集可用指标。重启保留任务、历史样本、基线打点、暂停、等待、方案、表单和卡片趋势。
- 管理员交接采用候选身份核验、采集线程保存屏障和一次性交接记录。取消授权或准备失败时，原实例继续监控。
- 修复进程组在工具交接及被测目标重启后累计值归零的问题，保留合计、成员累计和成员占位，并重新建立实例差分起点。
- 基本优先级显示“正常”“高”等名称，原始数据保留 Windows 编码。
- 将 Windows 上的“自愿上下文切换”更正为“上下文切换”。线程退出导致读数回落时跳过对应速率区间，平均值依据全量原始相邻样本的有效时间计算，长时查询通过索引连接断点。

## 升级须知

- 可从 1.4.1、2.0.0、2.0.1 或 2.0.2 在应用内检查更新，也可下载本页安装包升级。
- 2.0.2 及更早任务的 CPU 读数保留按核累计口径，并标明旧版。升级后新建任务和重新执行旧方案采用整机容量百分比。
- 管理员重启按实际采集权限触发。USS 等指标的可用性还取决于目标进程、会话和系统接口，重启后继续按实际结果显示。
- 1.4.1 首次升级会迁移数据库至 v5 并保留备份。升级前保存当前工作，并为迁移留出磁盘空间。
- 管理员实例的启动、停止、导出及退出命令要求客户端具备相应权限。正在进行的命令行等待或导出需完成后再交接。
- 本次安装包附 SHA-256 校验文件。2.x 更新器会校验安装包摘要，1.4.1 用户可先手动核对本页校验文件后安装。

## 验证范围

发布前源码阶段已通过指标原生对照、真实窗口交接、功能回归和源码/EXE 入口自检。Windows UAC 取消路径已有自动化覆盖，带提示窗口的实机取消交互待补测。详细记录见[阶段验收](https://github.com/liujialu0330/ProcessMonitor/blob/v2.0.3/doc/2026-11-15_指标采集与权限优化_阶段验收.md)。
