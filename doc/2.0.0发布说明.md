# 进程监控助手 2.0.0-beta.1 发布说明草案

本文件供预发布时使用。2.0 功能开发已完成，功能回归、远端 CI、性能、安装卸载、模拟更新及 A/B 回退验证均通过。2026-11-13 决定不以其余 24 小时长测、真机专项和多人内测作为本次源码提交门槛；这些项目未执行。当前保留 beta 版本号，本文件不代表已创建正式 Release，公网自动更新通道未实测。详见 [验收记录](2.0.0验收记录.md)。

## 升级须知

- 首次启动升级数据库至 v5，并保留 `monitor.db.bak_v1` 备份；同名备份存在时追加时间后缀。大库会显示迁移进度。
- 迁移前至少保留“原库大小 × 0.3 + 200 MB”可用空间；默认数据目录不变。
- 重复内存指标合并为“私有字节”；历史与导出页面合并为分析页。合并前的完整旧数据保留在备份中。
- 自动更新必须验证安装包 SHA-256。beta 安装包需手动下载，不进入正式版自动更新通道。

## 主要变化

- 支持进程树、同名进程组，分别查看合计与成员的增长趋势。
- 支持自动打点、日志触发、停止条件、阶段快照、命令行与无窗口运行。
- 完整测试方案可导入导出、多目标执行和共享打点；任务支持场景、版本、参考基线与星标。
- 最多四任务对比，按轮或时间对齐，导出对比图片和 CSV；较参考结论说明回归或不可比原因。
- 崩溃退出取证、重启续接、工具异常退出后续采与磁盘空间守卫。
- 报告三件套、证据包、复制结论和诊断信息便于附到缺陷单。
- 卡片/列表视图、统一快捷键、首次引导、设置导航与窄窗口适配。

## 回退

可覆盖安装 1.4.1：它看不到 2.0 历史样本，但可继续采集；再次升级时导回回退期间的新数据。
如使用迁移备份恢复，请先另存当前数据库；恢复备份会失去备份之后的记录。
