# 2.0.1 设置页导航修复验收

更新日期：2026-11-13。

## 问题与修复

2.0.0用户在设置页点击“监控默认值”等顶部分组时，会弹出“程序发生错误”，日志记录`AttributeError: 'bool' object has no attribute 'y'`。七个分组共用同一个错误连接方式。

`SettingPage._init_layout`的导航回调把分组保存在默认参数中，却没有接收`PivotItem.itemClicked`传入的布尔状态，导致分组对象被状态值覆盖。2.0.1显式接收并忽略选中状态，保留目标控件，并在点击时读取其当前位置。数据库结构仍为v5，本次没有修改存储或迁移逻辑。

## 自动化回归

- 新增14项真实鼠标点击用例：七个分组分别在800和1280宽度下操作，每项重复点击两次，检查没有未捕获异常、选中分组正确、滚动位置对应目标分组或页面底部。
- 修复前，新用例稳定复现同一个bool.y异常；修复后，设置页与版本相关87项测试通过。
- 本地完整功能回归：5006通过、44跳过、14未选中，388.36秒。跳过和未选中项目未计为通过。

## 真实窗口检查

通过Computer Use操作修复后的完整程序，使用独立临时数据目录，保留用户正在运行的2.0.0和日常监控数据。

| 展开主题卡片并切换深色 | 卡片展开导致后续分组位置变化，导航仍按实际位置滚动 | 通过 |

共完成16次分组导航点击。检查确认当前错误已修复，不代表所有功能都进行了人工穷举。

## 更新方式

2.0.0用户可用鼠标滚轮到设置页底部的“关于与更新”检查更新；旧版顶部分组导航仍有此缺陷。也可从 [v2.0.1 Release](https://github.com/liujialu0330/ProcessMonitor/releases/tag/v2.0.1) 下载安装包覆盖安装。

原2.0的性能、迁移、回退和未执行长测范围继续见 [2.0.0验收记录](2.0.0验收记录.md)。正式安装包由对应标签的构建与安装冒烟工作流生成，发布资产同时提供SHA-256校验文件。
