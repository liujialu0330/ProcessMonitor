# 2.0.2 分析导出与界面交互修复验收

更新日期：2026-11-14。

## 修复范围

2.0.1 安装后的真实界面检查发现三类问题：运行中任务的分析、报告和 CSV 没有共享同一数据快照；“方案”和任务列表“更多”菜单会刚弹出就消失；设置页的报告配色与迁移备份卡片会在特定布局下错位或裁剪。

### 分析与导出

分析请求现在把任务当时的最后采样时间作为闭区间终点。多指标并行读取若观察到不同终点，会以最早的终点重新读取整批，避免图表、摘要和结论混用多个采样时刻。报告图片、明细 CSV、摘要 CSV 和证据包统一使用合计分析结果的同一范围；后台流式导出也把该范围传到数据库查询。图表分桶查询本身接受相同终点，而不是在桶生成后只过滤桶标签。

进程组界面可以临时查看成员，但报告保持既有产品口径：导出合计序列，并在成员汇总段附成员结果。

### 菜单与设置布局

已安装的 Fluent `RoundMenu.exec()` 为非阻塞调用。方案菜单和任务列表菜单改由所属控件持有到 `closedSignal`，关闭后才释放，因此可点击菜单项。设置页的报告配色卡片现在只由导出分组管理；迁移备份卡片异步出现后会重新计算数据分组高度，诊断卡片不再被父容器裁剪。

## 自动化回归

- 历史查询、分析视图模型、报告、证据包、进程组分析、仓储边界、设置布局和真实菜单点击均增加或更新了回归用例。
- 回归覆盖导出后继续写样本、基线前样本排除、跨指标截止点重读、分桶不跨冻结截止点、成员查看不改变合计导出口径、菜单动作实际触发，以及迁移备份显隐后的设置页布局。
- Windows 离屏完整功能回归：5017 通过、44 跳过、14 未选中，耗时 318.04 秒；跳过、性能、浸泡和需要真窗口的项目不计为通过。
